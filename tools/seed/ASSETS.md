# Seed assets

Product images in `assets/` (`<shape>-<colour>-<view>.jpg`, 800x1000, 80 files, about 0.8 MB) are **placeholders generated in this
repo** by `pnpm --filter @vck/seed assets` (`src/gen-assets.ts`): flat vector garment silhouettes rendered with sharp.
Original artwork, no third-party source, no licence obligations.

| Source | Licence | Used for |
| --- | --- | --- |
| `src/gen-assets.ts` (this repo) | project licence | all 80 files, B1a mini seed |

B1b replaces them with at least 60 licensed photos; each source URL and licence goes in the table above before the files are committed.
