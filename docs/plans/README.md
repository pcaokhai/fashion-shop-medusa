# Plans
Output of the Superpowers `writing-plans` skill, one file per story: `VCK-<id>.md` (≤ 120 lines, docs/11 §4).
Header: story id, lane, branch, doc sections read, rulings (`R-<id>-<n>`: decision + reason).
Tasks: 2–5 minutes each, exact files, failing test first (with AC id), verification command.
Plans are kept after merge as a learning record and cited by PROGRESS entries.
