## Understanding
`make up` must start Postgres 16, Redis 7, Meilisearch, MinIO, Mailpit and placeholder VNPay/GHN sims (9100/9101),
return only when all are healthy (≤ 90 s), and `make down [v=1]` must stop them (v=1 also removes volumes).
`.env.example` documents every variable. Docker 29.4.2 / Compose v5.1.3 are installed and the daemon is running.

## Rulings
- **R-002-1** docs/02 §8 gives no MinIO or Mailpit ports and MinIO's default 9000 collides with backend-server (9000).
  MinIO API **9002**, console **9003**; Mailpit SMTP **1025**, UI **8025**. Add them to docs/02 §8 in this PR.
- **R-002-2** AC2 "wait until healthy" = `docker compose up -d --wait --wait-timeout 90` (no polling script).
  The dependent gated by health is `minio-init` (creates bucket `vck-media`, needed by VCK-005+): `depends_on: minio: service_healthy`.
  Fallback if `--wait` mishandles a one-shot exit-0 container: drop `minio-init`, move bucket creation to VCK-005.
- **R-002-3** Placeholder sims are 15-line Node http servers (`GET /health` → 200 JSON) mounted into `node:20-alpine`;
  no build step, no package.json (so they are not pnpm workspaces). VCK-208 (VNPay) and the GHN stories replace them (tools/CLAUDE.md layout).
- **R-002-4** All host ports bind `127.0.0.1` and are overridable (`${POSTGRES_PORT:-5432}` …) so a local Postgres does not block `make up`.
  Compose `name: vck` so volumes are `vck_*`. Dev credentials are placeholders (`vck`/`vck`), commented "dev only".
- **R-002-5** Image tags pinned exactly (no `latest`); Meilisearch tag is provisional until VCK-106 pins the version.
  No npm dependency added; Docker images are noted in the PR ("New dependency: <image>:<tag> — why").
