## Risks
- A draft that edits only some sections passes docs-check only if every section differs from its prompt; Summary prompt plus BREAKING lines differs, so the human gate relies on Metrics/other sections staying untouched. Accepted.
- Real history carries subjects with `(#n)`, one merge subject: handled by `--no-merges`; a later squash-only history is the supported shape.
- Git output encoding: subjects decoded as UTF-8; invalid bytes become U+FFFD, never crash.
- Renames are atomic per file, not across three files; rollback covers rename errors, a power cut mid-way is not covered (draft only, `git checkout` repairs).
