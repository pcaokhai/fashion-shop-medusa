## Understanding
Every PR runs lint, typecheck and tests for affected workspaces only, plus gitleaks, `pnpm audit --prod`, a licence check and a PR-title
check. Nothing exists in `.github/workflows/` yet. The repo is on GitHub (`pcaokhai/fashion-shop-medusa`), so the first real CI run
happens on this story's own PR. Inherited requirements: CI must also run `node --test scripts/*.test.mjs` (VCK-001 review) and should
run `make up` rather than copy image tags (VCK-002 review); `pnpm lint` does not lint `scripts/**`.

## Rulings
- **R-003-1** One workflow file `.github/workflows/ci.yml` for VCK-003; VCK-004 uses `contracts.yml`, so the two parallel branches never touch the same file.
- **R-003-2** Affected-only = `pnpm turbo run lint typecheck test --filter='...[origin/main]'` with `fetch-depth: 0`; the `scripts/` tests always run (root policy tests).
- **R-003-3** gitleaks runs as a pinned release binary with a verified SHA-256 (not `gitleaks-action`, whose licence terms differ for organisations); `pnpm audit --prod --audit-level critical`.
- **R-003-4** Licence check = `pnpm licenses list --prod --json` + `scripts/check-licenses.mjs` with an allowlist (MIT, Apache-2.0, BSD-2/3-Clause, ISC, 0BSD, CC0-1.0, BlueOak-1.0.0; docs/10 §7) and an explicit exceptions file `scripts/licence-exceptions.json` (each entry needs a reason). No new npm dependency.
- **R-003-5** PR title regex: `^(feat|fix|refactor|docs|test|chore|perf|ci)(\([a-z0-9-]+\))?!?: .+ \(VCK-\d{3}\)$` (types from git-workflow.md). Docs-fix PRs must cite the originating story id.
- **R-003-6** Supply chain: every third-party `uses:` pinned to a 40-char commit SHA with a `# vX.Y.Z` comment; workflow `permissions: contents: read`; `concurrency` cancels superseded runs; `timeout-minutes` on every job. A test enforces all three.
- **R-003-7** AC4 (≤ 12 min on the first 10 PRs) is a measurement, not code: each job writes its duration to the job summary; PROGRESS gets a follow-up to record the figure after 10 PRs. Caches: pnpm store (setup-node) and `.turbo`.
- **R-003-8** Integration job runs `make up` then `pnpm turbo run test:integration --filter='...[origin/main]'`; a `test:integration` task (cache off) is added to turbo.json. No workspace defines it yet, so turbo runs 0 tasks; the job is not skipped. Branch-protection required-checks are a repo setting: NOT changed by this story, surfaced to the user.
- **R-003-9** New dev dependency: `yaml` (workflow assertions in tests). Actions used: checkout, pnpm/action-setup, setup-node, actions/cache (versions and SHAs recorded in the PR).

Action SHAs go stale: Renovate (docs/10 §7) is a later story. Runner Docker/Compose versions for `make up` (needs `--wait-timeout`, Compose ≥ 2.17).
