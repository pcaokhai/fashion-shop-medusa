## Understanding
Every PR runs lint, typecheck and tests for affected workspaces only, plus gitleaks, `pnpm audit --prod`, a licence check and a PR-title
check. Nothing exists in `.github/workflows/` yet. The repo is on GitHub (`pcaokhai/fashion-shop-medusa`), so the first real CI run
happens on this story's own PR. Inherited requirements: CI must also run `node --test scripts/*.test.mjs` (VCK-001 review) and should
run `make up` rather than copy image tags (VCK-002 review); `pnpm lint` does not lint `scripts/**`.

## Rulings
- **R-003-1** Two workflow files for this story: `ci.yml` (checks, integration, security, pins) and `pr-title.yml` (pr-title). VCK-004's `contracts.yml` is separate, so parallel branches never touch the same file.
- **R-003-2** Affected-only = `pnpm turbo run lint typecheck test --filter='...[origin/main]'` with `fetch-depth: 0`; the `scripts/` tests always run (root policy tests).
- **R-003-3** gitleaks runs as a pinned release binary with a verified SHA-256 (not `gitleaks-action`, whose licence terms differ for organisations); `pnpm audit --prod --audit-level critical`.
- **R-003-4** Licence check = `pnpm licenses list --prod --json` + `scripts/check-licenses.mjs` with an allowlist (MIT, Apache-2.0, BSD-2/3-Clause, ISC, 0BSD, CC0-1.0, BlueOak-1.0.0; docs/10 §7) and an explicit exceptions file `scripts/licence-exceptions.json` (each entry needs a reason). No new npm dependency.
- **R-003-5** PR title regex: `^(feat|fix|refactor|docs|test|chore|perf|ci)(\([a-z0-9-]+\))?!?: \S.* \(VCK-\d{3}\)$` (types from git-workflow.md). Docs-fix PRs must cite the originating story id.
- **R-003-6** Supply chain: every third-party `uses:` pinned to a 40-char commit SHA with a `# vX.Y.Z` comment; workflow `permissions: contents: read`; `concurrency` cancels superseded runs; `timeout-minutes` on every job. A test enforces all three.
- **R-003-7** AC4 (≤ 12 min on the first 10 PRs) is a measurement, not code: each job writes its duration to the job summary; PROGRESS gets a follow-up to record the figure after 10 PRs. Caches: pnpm store (setup-node) and `.turbo`.
- **R-003-8** Integration job runs `make up` then `pnpm turbo run test:integration --filter='...[origin/main]'`; a `test:integration` task (cache off) is added to turbo.json. No workspace defines it yet, so turbo runs 0 tasks; the job is not skipped. Branch protection is a repo setting: see R-003-16.
- **R-003-9** New dev dependency: `yaml` (workflow assertions in tests). Actions used: checkout, pnpm/action-setup, setup-node, actions/cache (versions and SHAs recorded in the PR).
- **R-003-10** `pins` job runs `scripts/check-action-pins.mjs`: every `uses:` tag comment is resolved to a commit (annotated tags dereferenced) and must equal the pinned SHA; any mismatch or resolution error fails closed.
- **R-003-11** `.gitleaks.toml`: `useDefault = true` plus one `[[allowlists]]` entry (path AND exact fake token, contracts/fixtures). Needs gitleaks >= 8.25; older binaries ignore `[[allowlists]]`, which fails closed (findings return).
- **R-003-12** PR title description must start with a non-space (`\S.*`): blank descriptions fail.
- **R-003-13** All jobs `runs-on: ubuntu-24.04` (`ubuntu-latest` moves to 26 on 2026-10-19; `make up` needs known Docker/Compose); `persist-credentials: false` on every checkout; job-id set is exact and no job has an `if:` (a skipped required check passes); group prefixes differ per workflow.
- **R-003-14** OSV scanning (docs/10 §7) is deferred: not in the AC. PLAT follow-up together with Renovate.
- **R-003-15** Licence allowlist adds 0BSD, CC0-1.0, BlueOak-1.0.0 beyond docs/10 §7 (MIT/Apache/BSD/ISC).
- **R-003-16** Branch protection/rulesets API returns 403 on this private free-plan repo: the checks are ADVISORY until the user upgrades or makes the repo public. Required names when possible: checks, integration, security, pins, pr-title.

Action SHAs go stale: Renovate (docs/10 §7) is a later story. Runner Docker/Compose versions for `make up` (needs `--wait-timeout`, Compose ≥ 2.17).
